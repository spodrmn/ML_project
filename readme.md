# CSCI 111 Machine Learning Project - NBA Draft Basketball Player Data 1989-2021

This folder contains the .py files containing the python code that generates the models and outputs for our group's CSCI 111 Machine Learning Project, 
as well as other necessary supplementary files and documents.

## Libraries Used
Make sure to install the following libraries:
* pandas
* scikit-learn
* seaborn
* matplotlib

## Files Needed
Make sure both of these files are saved in the exact same folder:
* `final_project.py` (the main python script)
* `final_dataset.csv` (the dataset)

## Important note (reading the output and graphs):
When you run the code, some results will appear right in the terminal (like the accuracy scores and best k values) and some will appear as popups (like the graphs and confusion matrices). 

Important: you have to close the graphs' popups for the other part of the code to show. The script actually pauses when a plot opens, so just exit out of the graph window when you are done looking at it to let the rest of the code finish running in the terminal.
